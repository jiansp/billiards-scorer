# 台球追分计分器（React）

手机浏览器友好的九球追分计分工具，支持 **2 人 / 3 人**，数据自动保存在本地（刷新不丢失）。

## 功能
- 2 人或 3 人模式，昵称 / 起始分可自定义
- 一键记录：普胜、小金、大金、黄金九、黑金、犯规
- 自动按"上家 / 本家 / 下家"关系结算分数（两人模式下对手即为上下家）
- 防误触：撤销上一步、查看得分记录
- 每位玩家的犯规次数统计，显示在各自分数下方（撤销会自动回退）
- 破产提示（分数 ≤ 0）
- 计分规则可在设置里自定义（适配不同球房习惯，如东北 1356、海南黄金九 等）
- 可"添加到主屏幕"当 App 用，竖屏优先、大按钮适配手机

## 计分体系（默认「14710」）
| 事件 | 触发 | 本家净得（3 人） |
| --- | --- | --- |
| 普胜 | 接手后清台 | 上家赔 +4 |
| 小金 | 开球未下·接杆清台 | 上家赔 +7 |
| 大金 | 开球有下·一杆清台 | 上下家各赔 10（共 +20） |
| 黄金九 | 开球/传进 9 号 | 上下家各赔 4（共 +8） |
| 黑金 | 清台母球落袋 | 本家赔上下家各 10（共 -20） |
| 犯规 | 失误/犯规 | 本家给上家 1 分，下家获自由球 |

## 部署：GitHub Pages（自动）

本仓库已配置 GitHub Actions 工作流 `.github/workflows/deploy.yml`：
向 `main` 分支推送后会自动 `npm ci && npm run build` 并把 `dist/` 发布到 Pages。

首次部署需在仓库 **Settings → Pages → Source** 选 **GitHub Actions**（工作流里的 `enablement: true` 会自动创建站点）。

日常更新只需：

```bash
git add .
git commit -m "说明"
git push
```

推送后在仓库 **Actions** 标签查看进度，两条 job（build / deploy）全绿即发布完成，约 1–2 分钟。

## 本地运行
```bash
npm install
npm run dev      # 本地开发，终端会给出局域网地址，手机同一 WiFi 可访问
npm run build    # 产出 dist/ 静态文件
npm run preview  # 预览构建产物
```

`vite.config.ts` 中 `base: './'`，构建产物使用相对路径，放在任意静态托管（含 Pages 子路径）都能正常加载。
